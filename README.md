# College Chatbot (NLP + Tkinter)

## Description
A rule-based chatbot that answers college-related queries like admission, fees, exams, and facilities.

## Features
- NLP-based keyword matching
- GUI using Tkinter
- Handles multiple query types

## Technologies Used
- Python
- Tkinter
- NLP (Rule-based)

## How to Run
1. Install Python
2. Run:
   python main.py
